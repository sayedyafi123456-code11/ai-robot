# AURA — Virtual AI Robot

A browser-based full-body 3D virtual robot prototype built with Three.js.

## Run locally
Open `index.html` in a modern browser with an internet connection. Three.js loads from jsDelivr.

## Features
- Animated full-body 3D robot avatar
- Mouse-follow movement
- Greeting, wave, and dance actions
- Browser text-to-speech and optional speech recognition
- Responsive layout for desktop and mobile

## Note
This is Stage 01: a front-end prototype. Voice responses are simple local demo responses, not a connected AI model. An AI backend can be added in a later stage.
